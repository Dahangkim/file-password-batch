# 파일 일괄 암호 설정기

여러 파일에 열기 암호를 한 번에 설정하는 Windows 10/11 64비트용 시험판입니다.

## 다운로드

**[Windows 0.1.3 다운로드와 사용 안내](https://github.com/Dahangkim/file-password-batch/releases/tag/v0.1.3)**

위 페이지의 Assets에서 `FilePasswordBatch-Windows-0.1.3.zip`을 받으세요. 압축을 풀고 `FilePasswordBatch.exe`를 실행합니다. 별도 설치나 Python 설치는 필요하지 않습니다.

## 사용법과 기능

파일 또는 폴더 추가 → 저장 위치 선택 → 같은 암호 두 번 입력 → 암호 설정 시작 → 결과 확인

- 한글 HWP/HWPX: 설치된 한글 자체 암호 기능 사용. 2024에서 저장과 암호화 표시 검사, 2018 실기 미검증.
- PDF: AES-256 열기 암호.
- XLSX: 4KB 이상 지원, Excel 설치 불필요. 복호화 원본 일치 검사.
- JPG/JPEG/PNG: 사진별 암호화 PDF로 변환.
- 상위 폴더, 하위 폴더 구조와 빈 폴더 유지.
- 암호: 공백 없는 영문, 숫자, 특수문자 10~32자.

## 보안과 주의사항

파일은 PC 안에서 처리하며 프로그램이 파일 내용이나 암호를 외부로 전송하거나 AI에 보내는 기능은 없습니다. 클라우드 동기화 폴더는 해당 서비스 설정에 따라 동기화됩니다.

원본은 암호 없이 그대로 남습니다. 원본을 별도로 관리하고, 결과 파일을 직접 열어 확인하세요. 암호 저장이나 복구 기능은 없습니다. 파일명은 암호화되지 않습니다.

시험판이므로 비식별 시험자료로 먼저 확인하세요. 코드 서명이 없어 Windows 경고가 나타날 수 있습니다. 보안 기능을 끄지 말고 기관의 실행 정책을 따르세요.

한컴오피스는 포함하지 않습니다. 상세 제한과 구성요소 고지는 배포 ZIP의 사용안내.txt와 THIRD_PARTY_NOTICES.txt를 참고하세요.
